Overages off limits spending, not interruptions

Team extra spending being disabled is not a control on a separate Anthropic API account. Leave PI_CLAUDE_SUBSCRIPTION_API_KEY_FALLBACK=0, including in provider-scoped orchestration settings.

The fallback is opt-in, not automatic after a rate limit. A key alone does not enable it. The subscription CLI path strips key/auth-token/provider-switch variables. Selecting another API-backed Pi provider is outside that protection.

The billing issue was closed because extra spending is disabled, without an account usage-pool measurement. Successful requests and Pi dollar estimates do not identify the pool. Exhausted or unavailable entitlements can stop the work rather than continue on billed overages.

Audit mode implemented from your feedback

Implemented on feat/local-audit, not yet released or installed. Safe local audit logging is separate from raw stderr debug output. 58 focused tests and 569 full-suite tests pass, with the known packed-loader check still skipped.

One opt-in local ledger

Enable with PI_CLAUDE_SUBSCRIPTION_AUDIT=1. Off by default, independent of verbose debug, and no files created while off.

Default path: <installed-extension>/.audit/YYYY-MM-DD.jsonl. Resolve it from the extension, not the project or CLI temp directory. Exclude it from Git and package contents.

Use owner-only permissions, bounded rotation/retention and concurrent-safe appends. An unwritable directory must produce a visible audit-unavailable warning. Do not silently move the log or claim recording succeeded.

Errors and successful usage together

Record UTC time, generated request ID, versions, model, CLI/API route, replay/resume mode, terminal reason, safe status codes, relay counts, cleanup outcomes and known token/cache buckets. Label dollar estimates as API-equivalent estimates, not bills.

Cover startup, preflight rejection, auth/rate limits, hook/CLI/protocol errors, partial output, cancellation, timeouts and successful text/tool/length stops. Count provider invocations, not human prompts. Missing usage is unknown, not zero.

No prompts, outputs, tool arguments/results, attachments, headers, credentials, account identifiers or raw error/stderr text.

Two limits the audit must state honestly

  • A module-load failure occurs before extension code can run. The new explicit src/audit-loader-check.mjs uses the installed SDK loader and records a sanitized outcome in the same directory, without a model request. It is not an automatic recorder for every Pi startup, and it does not fix the known import defect.
  • A hard kill can leave a request-start record without a terminal record. Report it as incomplete. Logs cannot recover unknown usage or establish which Team billing pool was charged.

Keep a separate local verification manifest for the revision, versions, pass/fail/skipped checks and evidence links. The skipped loader check stays unmet; historical CI/cache runs do not become fresh weekly acceptance merely by being copied into the manifest.
